## Instalación
1. Clona el repositorio:
    ```bash
    git clone https://github.com/Maikcyphlock/hackathon2025-frontend.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd hackathon2025-frontend
    ```
3. Instala las dependencias:
    ```bash
    npm install
    ```

## Uso
Para iniciar la aplicación en modo de desarrollo:
```bash
npm start
```
